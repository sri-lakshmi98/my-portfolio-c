# Shri Lakshmi: portfolio

Portfolio site for M. Shri Lakshmi, a web and UI/UX designer. A chibi character on a canvas follows the cursor, with a scroll-drawn "My journey" section, selected work and an Aadithya case study page.

Built with React, TypeScript, Vite and Tailwind CSS.

```
npm install --no-package-lock
npm run dev
npm run build
```

The character is drawn from still frames in `public/frames`. `src/gaze.ts` maps each frame to a cursor direction.
